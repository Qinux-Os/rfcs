# Superseded RFCs

Accepted RFCs that were later replaced.

**Never delete an RFC.** An RFC that was accepted and then reversed is the most
useful document in this directory: it records what was tried, why it seemed
right, and what went wrong. Deleting it guarantees the mistake gets repeated.

## Format

When an RFC is superseded:

1. Move the file here, keeping its original number.
2. Change its status header to `Superseded by RFC-NNNN`.
3. Add a note at the top:

   ```markdown
   > **Superseded by [RFC 0002](0002-short-title.md)** on YYYY-MM-DD.
   > The original decision is kept for the record. See the superseding RFC for
   > what changed and why.
   ```

4. Add a row to the superseded table in [`../README.md`](../README.md).

The original text is **not** edited, apart from the status header. Editing the
body would misrepresent what was originally agreed.
